# Bookrats web

React 19 + Vite + TypeScript + Tailwind v4 PWA, served by the backend at `/app`.

```bash
npm ci
npm test          # Vitest
npm run lint      # Biome lint + format check (config: ../biome.json)
npm run format    # Biome: apply formatting, import sorting and safe fixes
npm run build     # tsc -b && vite build -> dist/
```
